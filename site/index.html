Gravador de Calls English

Grave as suas calls, aba por aba

Extensão do Chrome que grava sozinha o áudio dos outros participantes das calls do Google Meet e do Microsoft Teams. Tudo fica no seu computador.

Instalar pela Chrome Web Store Política de privacidade

O que ele faz

Começa sozinho

Quando a call começa de fato (depois da tela de entrada e da sala de espera), a gravação daquela aba começa sem clique. O ícone mostra REC na aba.

Uma gravação por aba

Três calls abertas ao mesmo tempo viram três gravações separadas, sem misturar o áudio de uma com o da outra.

Só os outros participantes

Grava o áudio que a página da call recebe das outras pessoas. O seu microfone nunca entra na gravação, a menos que você ligue Gravar a minha voz nas configurações: aí a sua voz vai para um arquivo separado, só enquanto o seu microfone estiver aberto na call.

Salva com os dados da call

No fim, o áudio (audio.webm) e um info.json com título, data, duração e os nomes dos participantes vão para Downloads/Gravações de calls (Downloads/Call recordings com o Chrome em inglês), numa pasta por call.

Modo aba

Se uma call não pegar áudio, o atalho Alt+Shift+G grava o que a aba toca, também em outros sites.

Volume desta aba

Ajuste o volume de qualquer aba de 0% a 200% pelo popup, sem mudar o nível das gravações.

Sair quando a call esvaziar

Opcional e desligado por padrão: sai da call e fecha a aba quando você fica sozinho ou quando quase todos já saíram, depois de salvar a gravação.

Avançado: pasta escolhida e transcrição

Gravar numa pasta à sua escolha e transcrever cada call no próprio computador exigem o helper local, que ainda não é distribuído pela loja. Sem ele, tudo acima funciona normalmente.

Transcrever no seu computador

Transcrever cada call na sua própria máquina, sem mandar áudio para fora, exige o whisper.cpp, o ffmpeg e um modelo de reconhecimento de fala. A extensão mostra este mesmo passo a passo em Configurações, na seção Transcrição. Se você usa o Claude Code, copie o prompt abaixo e cole nele: ele instala tudo e liga a extensão ao programa que transcreve.

Instalar a transcrição local da extensão Gravador de Calls

Estou no macOS e quero transcrever as minhas calls no meu próprio computador, sem mandar o áudio para fora. A extensão Gravador de Calls já está instalada no Chrome. Falta instalar o programa que transcreve e ligar os dois. Faça isso por mim.

Projeto: https://github.com/jefersonftlopes/gravador-de-calls

Regras

1. Confira cada passo antes de começar o seguinte, e me diga o que achou.
2. Avise antes do download grande (o modelo de fala, 1,6 GB) e espere eu confirmar.
3. NÃO rode npm install neste projeto. O programa que transcreve, o worker e o teste importam só módulos do Node e caminhos relativos, e npm run funciona sem a pasta node_modules. Isso poupa centenas de MB.
4. Se um passo falhar, pare e me explique em linguagem simples o que deu errado e o que eu posso fazer.
5. Nunca apague arquivo meu e nunca mexa nas minhas gravações.
6. Se precisar da minha senha, pare e me diga o comando para eu rodar. Não peça a senha.

Passos

1. Conferir que este é um Mac: o programa que transcreve só tem instalador para macOS.
   Comandos:
       uname -s
   Confira: `uname -s` responde Darwin. Em qualquer outro sistema, pare e me diga que o instalador existe só para macOS.

2. O Node 22, o whisper.cpp e o ffmpeg, instalados pelo Homebrew.
   Comandos:
       brew install node
       brew install whisper-cpp
       brew install ffmpeg
   Confira: `node --version` é 22 ou mais novo, `whisper-cli --help` responde (ele fica em /opt/homebrew/bin/whisper-cli) e `ffmpeg -version` responde.

3. O projeto da extensão, baixado do GitHub para ~/Documents/gravador-de-calls.
   Comandos:
       git clone https://github.com/jefersonftlopes/gravador-de-calls.git ~/Documents/gravador-de-calls
   Confira: o arquivo package.json existe em ~/Documents/gravador-de-calls.

4. O modelo de reconhecimento de fala: 1,6 GB de download, o passo mais demorado.
   Comandos:
       mkdir -p "$HOME/Library/Application Support/gravador-de-calls/modelos"
       curl -L --fail -o "$HOME/Library/Application Support/gravador-de-calls/modelos/ggml-large-v3-turbo.bin" https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
       stat -f%z "$HOME/Library/Application Support/gravador-de-calls/modelos/ggml-large-v3-turbo.bin"
   Confira: o arquivo baixado tem exatamente 1624555275 bytes. Um arquivo cortado faz o whisper falhar sem explicar a causa.

5. A ligação entre a extensão do Chrome e o programa que transcreve.
   Comandos:
       cd ~/Documents/gravador-de-calls
       npm run instalar -- --id kpbjnbedejcbakdjacjmhaofidooddjp
   Confira: o comando terminou sem erro e o id kpbjnbedejcbakdjacjmhaofidooddjp aparece no manifesto do host que ele escreveu.

6. Uma call de teste, falada pelo próprio Mac, para provar que a transcrição funciona de ponta a ponta.
   Comandos:
       cd ~/Documents/gravador-de-calls
       npm run teste:transcricao-real
   Confira: o teste terminou dizendo que passou. Ele roda numa pasta temporária e não toca nas minhas gravações.

7. Uma conferência final, que mostra o que ficou pronto e em que pasta as minhas gravações vão cair.
   Comandos:
       cd ~/Documents/gravador-de-calls
       npm run verificar
   Confira: o comando terminou dizendo "Tudo pronto". Ele só lê, nunca muda nada, e termina com erro quando falta alguma peça.

No fim, me diga

1. Traduza para mim a saída do último comando, em palavras de quem não é técnico: o que ficou pronto e o que ainda falta.
2. Diga em que pasta as minhas gravações vão cair, a que o comando mostrou.
3. Diga que eu não preciso configurar nada na extensão: a transcrição no meu computador já fica ligada. É só abrir as configurações, conferir que "O seu computador" está escolhido em Transcrição e ver a frase "Pronto para transcrever".

O instalador existe só para macOS. Em outros sistemas, a transcrição pela API do provedor, com a sua chave, funciona do mesmo jeito. Código em github.com/jefersonftlopes/gravador-de-calls.

Tudo fica no seu computador

A extensão não tem servidor, não pede conta e não tem analytics. As gravações ficam na sua pasta Downloads (ou na pasta escolhida, com o helper local), e o áudio de uma call em andamento fica guardado no próprio navegador só até ser salvo. Nada é enviado para a Enkode nem para ninguém. Detalhes na política de privacidade.

Avise quem está na call

Gravar uma conversa pode exigir o consentimento de todos os participantes, conforme o país e o estado (no Brasil, a LGPD; em vários lugares, o consentimento de todas as partes). Quem decide gravar é você, e avisar os participantes é responsabilidade sua.

Google Meet e Microsoft Teams são marcas dos seus respectivos titulares. O Gravador de Calls é uma ferramenta independente, sem afiliação, patrocínio ou endosso do Google ou da Microsoft.
