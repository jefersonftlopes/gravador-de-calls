Gravador de Calls Português

Record your calls, tab by tab

A Chrome extension that automatically records the audio of the other participants in Google Meet and Microsoft Teams calls. Everything stays on your computer.

Add from the Chrome Web Store Privacy policy

What it does

Starts on its own

When the call actually starts (past the join screen and the waiting room), recording of that tab begins without a click. The icon shows REC on the tab.

One recording per tab

Three calls open at the same time become three separate recordings, with no audio mixed from one into another.

Only the other participants

It records the audio the call page receives from the other people. Your microphone is never recorded.

Saved with the call details

At the end, the audio (audio.webm) and an info.json with the title, date, duration and participants' names go to Downloads/Call recordings (Downloads/Gravações de calls when Chrome is in Portuguese), one folder per call.

Tab mode

If a call does not pick up audio, the Alt+Shift+G shortcut records what the tab plays, on other sites too.

Volume for this tab

Set the volume of any tab from 0% to 200% in the popup, without changing the level of the recordings.

Leave when the call empties

Optional and off by default: leaves the call and closes the tab when you are alone or almost everyone has left, after the recording is saved.

Advanced: chosen folder and transcription

Saving to a folder of your choice and transcribing each call on your own computer require the local helper, which is not yet distributed through the store. Without it, everything above works normally.

Transcribe on your own computer

Transcribing each call on your own machine, without sending audio anywhere, needs whisper.cpp, ffmpeg and a speech recognition model. The extension shows this same step by step under Settings, in the Transcription section. If you use Claude Code, copy the prompt below and paste it there: it installs everything and connects the extension to the program that transcribes.

Install local transcription for the Gravador de Calls extension

I am on macOS and I want my calls transcribed on my own computer, without sending the audio anywhere. The Gravador de Calls extension is already installed in Chrome. What is missing is the program that transcribes and the link between the two. Please do it for me.

Project: https://github.com/jefersonftlopes/gravador-de-calls

Rules

1. Check each step before starting the next one, and tell me what you found.
2. Warn me before the big download (the speech model, 1.6 GB) and wait for me to confirm.
3. Do NOT run npm install in this project. The program that transcribes, the worker and the test import only Node modules and relative paths, and npm run works without the node_modules folder. This saves hundreds of MB.
4. If a step fails, stop and explain in plain language what went wrong and what I can do.
5. Never delete a file of mine and never touch my recordings.
6. If you need my password, stop and tell me the command to run. Do not ask for the password.

Steps

1. Check that this is a Mac: the program that transcribes only has a macOS installer.
   Commands:
       uname -s
   Check: `uname -s` answers Darwin. On any other system, stop and tell me the installer only exists for macOS.

2. Node 22, whisper.cpp and ffmpeg, installed with Homebrew.
   Commands:
       brew install node
       brew install whisper-cpp
       brew install ffmpeg
   Check: `node --version` is 22 or newer, `whisper-cli --help` answers (it lives in /opt/homebrew/bin/whisper-cli) and `ffmpeg -version` answers.

3. The extension project, downloaded from GitHub into ~/Documents/gravador-de-calls.
   Commands:
       git clone https://github.com/jefersonftlopes/gravador-de-calls.git ~/Documents/gravador-de-calls
   Check: the file package.json exists in ~/Documents/gravador-de-calls.

4. The speech recognition model: a 1.6 GB download, the longest step.
   Commands:
       mkdir -p "$HOME/Library/Application Support/gravador-de-calls/modelos"
       curl -L --fail -o "$HOME/Library/Application Support/gravador-de-calls/modelos/ggml-large-v3-turbo.bin" https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
       stat -f%z "$HOME/Library/Application Support/gravador-de-calls/modelos/ggml-large-v3-turbo.bin"
   Check: the downloaded file is exactly 1624555275 bytes. A truncated file makes whisper fail without explaining why.

5. The link between the Chrome extension and the program that transcribes.
   Commands:
       cd ~/Documents/gravador-de-calls
       npm run instalar -- --id kpbjnbedejcbakdjacjmhaofidooddjp
   Check: the command finished without errors and the id kpbjnbedejcbakdjacjmhaofidooddjp appears in the host manifest it wrote.

6. A test call, spoken by the Mac itself, to prove transcription works end to end.
   Commands:
       cd ~/Documents/gravador-de-calls
       npm run teste:transcricao-real
   Check: the test finished saying it passed. It runs in a temporary folder and never touches my recordings.

What is left for me at the end

1. Choose the recordings folder in the extension settings.
2. Leave the option "Your computer" selected under Transcription, in the extension settings.

The installer only exists for macOS. On other systems, transcription through the provider API, with your own key, works just the same. Code at github.com/jefersonftlopes/gravador-de-calls.

Everything stays on your computer

The extension has no server, no account and no analytics. Recordings stay in your Downloads folder (or in the folder you choose, with the local helper), and the audio of a call in progress is kept in the browser only until it is saved. Nothing is sent to Enkode or anyone else. Details in the privacy policy.

Tell the people on the call

Recording a conversation may require the consent of every participant, depending on the country and state (in Brazil, the LGPD; in many places, all-party consent laws). You decide to record, and informing the participants is your responsibility.
